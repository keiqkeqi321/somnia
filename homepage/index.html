能力索引

从通用对话到复杂工程任务，一套分层的能力架构，把「能聊天」变成「能交付」。

C—01 通用能力General Agent 开箱即用的通用智能体：理解自然语言指令，自主规划步骤、读写文件、执行命令、浏览网络，覆盖研发、写作、分析等日常任务。 → C—02 MCP 工具生态Model Context Protocol 原生支持 MCP 协议，一键接入数据库、浏览器、设计工具、内部 API 等成百上千的 MCP Server，让 Agent 伸进你的整个工具链。 → C—03 Skills 技能插件Pluggable Skills 可插拔的技能包机制，把领域知识、工作流与最佳实践封装成 Skill，即装即用，也可以自己编写并分享给团队。 → C—04 Subagent 分工Parallel Subagents 主 Agent 派生专职子 Agent，各自拥有独立上下文，并行处理子任务、互不污染，结果自动汇总交付。 → C—05 Agent Team 协同Agent Team 把多个 Agent 编成一支团队：架构师、开发者、测试、评审各司其职，像真实团队一样协作交付复杂项目。 →
02 /

多端，随处可用

终端里的极客模式、桌面端的完整体验、浏览器里的远程接管 —— 同一套能力，四种打开方式。

CLI

Terminal
终端原生命令行

开发者最熟悉的主场。一条命令唤起 Agent，脚本化、可管道、可嵌入 CI，与 Git 工作流无缝融合。

Desktop

Windows / macOS
原生桌面客户端

图形化工作台：会话管理、Skill 市场、MCP 配置、任务看板一应俱全，双端原生体验。

Web Remote

Browser
Desktop 的远程入口 · somnia.top/app/#/connect ↗

桌面端开启远程服务后，打开 somnia.top/app/#/connect 登录托管入口，即可从任何浏览器安全接入同一台 Agent 主机 —— 出门在外，任务照跑。

状态同步

Seamless
跨端连续工作

在 CLI 里发起的任务，回到桌面端继续查看；路上用 Web Remote 跟进进度。上下文连续，工作不中断。
